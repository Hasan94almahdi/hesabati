# Hesabati 0.2

تحديث تدريجي من MVP 0.1. انشر الملفات الستة داخل جذر مستودع GitHub Pages نفسه.

## ما الجديد
- حسابات مالية مستقلة مع رصيد افتتاحي، وإظهار الحركات المرتبطة بها.
- تحويلات بين حسابين بنفس العملة.
- دفعات جزئية للطلبات؛ الدفعة تنشئ حركة إيراد واحدة مرتبطة بالطلب.
- ديون ومستحقات مع علامة تسديد (التسديد لا ينشئ حركة نقدية تلقائياً).
- مهام منفصلة عن المتابعات.
- نسخة احتياطية JSON تتضمن الجداول الجديدة.

## سلامة البيانات
- يستخدم نفس IndexedDB باسم `hesabati-v1` مع ترقية المخطط من 1 إلى 2.
- لا تحذف بيانات Safari أو التطبيق.
- قبل رفع الملفات: من الإعدادات صدّر نسخة احتياطية، واحفظها في Files/iCloud Drive.
- بعد الرفع، افتح التطبيق وتحقق من ظهور العملاء والعمليات القديمة.
- لا تتضمن النسخة الحالية استعادة النسخة الاحتياطية أو المزامنة السحابية.
- اختبر التحديث ببيانات تجريبية قبل الاعتماد عليه للإدارة المالية الحقيقية.

## حدود النسخة
- الحسابات الافتراضية «نقدي» و«بنك» بالليرة التركية.
- المصروف والإيراد اليدوي يختار الحساب الافتراضي؛ إنشاء حسابات جديدة متاح.
- أسعار الصرف والتحويل متعدد العملات غير مطبّقة.
- ربط دفعات الطلبات يفترض أنها من نطاق العمل.
- تتبع العادات والتقارير المتقدمة وعمليات التعديل والحذف والمزامنة غير مطبقة بعد.
