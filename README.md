# حساباتي — Hesabati MVP 0.1

نسخة PWA أولية عربية بواجهة Minimal. تعمل بقاعدة IndexedDB محلية في المتصفح.

## التشغيل على iPhone
1. ارفع **محتويات** هذا المجلد إلى استضافة HTTPS مجانية تدعم الملفات الثابتة (مثل GitHub Pages).
2. افتح رابط HTTPS الناتج باستخدام Safari على الآيفون.
3. من مشاركة Safari اختر «إضافة إلى الشاشة الرئيسية» ثم افتح الأيقونة.
4. افتح التطبيق مرة واحدة أثناء توفر الإنترنت لتخزين ملفات التطبيق، وبعد ذلك جرّب فتحه دون اتصال.

## ما يعمل الآن
- إضافة عملاء، طلبات، متابعات، إيرادات، مصاريف.
- قوائم وعرض ملخص نقدي مفصول حسب العملة والقسم.
- حفظ محلي في IndexedDB، وتخزين ملفات التطبيق عبر Service Worker.
- تصدير نسخة احتياطية JSON يدوياً.

## غير منفذ بعد
- قاعدة PostgreSQL سحابية، تسجيل الدخول، مزامنة وتعارضات.
- الدفعات الجزئية وربط الدفعات بالطلبات، أرصدة الحسابات الحقيقية، التحويلات، أسعار الصرف، الذمم.
- إشعارات الآيفون، استيراد النسخ الاحتياطية، تحرير وحذف السجلات.

**تنبيه:** لا تستخدم بيانات مالية أو بيانات عملاء حقيقية وحساسة قبل تنفيذ الأمان والمزامنة والنسخ الاحتياطي والاستعادة. إزالة بيانات Safari قد تمحو السجلات المحلية. التخزين المحلي ليس بديلاً عن النسخ الاحتياطي.
