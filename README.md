# حساباتي 1.0

تطبيق حسابات عربي RTL مصمم للآيفون، يعمل كتطبيق ويب تقدمي PWA دون إنترنت بعد أول زيارة. البيانات محلية داخل IndexedDB ولا تُرسل إلى خادم.

## الوظائف

- دفتر حركات مزدوج: كل حركة مدينة ودائنة ومتزنة لكل عملة.
- حسابات نقدية وبنكية ومحافظ متعددة العملات.
- تحويلات داخل العملة وتحويلات عملات مع تسجيل سعر الصرف.
- عملاء وطلبات ودفعات جزئية وتكاليف مدفوعة أو آجلة.
- قيمة الطلب، المقبوض، المتبقي، الربح المتوقع، وصافي النقد الحالي.
- ديون لنا أو علينا مع تسويات جزئية مرتبطة بحساب مالي.
- تصنيفات وميزانيات شهرية ومقارنة الفعلي بالمخطط.
- تقارير يومية وشهرية وسنوية مع أقسام العمل والشخصي والبيت.
- مهام عامة ومتابعات مرتبطة بالعملاء.
- تصدير واستعادة نسخة JSON كاملة، وفحص سلامة البيانات.
- ترحيل آمن من Hesabati 0.2 مع نسخة داخلية قبل الترحيل.
- سجل مراجعة، وعكس الحركات اليدوية بدلاً من حذفها.

## النشر على GitHub Pages

1. فك ملف hesabati-1.0-github-pages.zip.
2. ارفع محتوياته كما هي إلى جذر مستودع GitHub Pages.
3. من إعدادات المستودع اختر Pages ثم النشر من فرع main والمجلد / (root).
4. افتح رابط Pages مرة واحدة مع اتصال بالإنترنت.
5. في Safari على الآيفون: مشاركة ← إضافة إلى الشاشة الرئيسية.

كل المسارات والملفات نسبية، لذلك يعمل التطبيق في جذر النطاق أو داخل مسار مستودع مثل /hesabati/.

## الترقية من 0.2

اقرأ [UPGRADE.md](UPGRADE.md) قبل استبدال الملفات. لا تحذف بيانات Safari، ولا تغيّر رابط GitHub Pages أثناء الترقية.

## التطوير والاختبار

لا يحتاج التطبيق إلى بناء أو مكتبات وقت التشغيل. لتشغيل الاختبارات:

    npm install
    npm test

وللمعاينة محلياً:

    python3 -m http.server 4173

ثم افتح http://127.0.0.1:4173/.

## التخزين والمحاسبة

- اسم قاعدة البيانات محفوظ كما هو: hesabati-v1.
- ينتقل مخطط IndexedDB من الإصدار 2 إلى الإصدار 7.
- جداول 0.2 الأصلية تبقى موجودة، وتُضاف الجداول الجديدة.
- الإيراد المقبوض: مدين للحساب المالي ودائن للإيراد.
- المصروف المدفوع: مدين للمصروف ودائن للحساب المالي.
- دفعة الطلب تُسجل إيراداً نقدياً، أما قيمة الطلب وحدها فلا تغير رصيد الحساب.
- تكلفة الطلب تُسجل وقت إنشائها، وإذا كانت آجلة تُقابل ذمة دائنة حتى تسديدها.
- التحويل لا يدخل في الإيراد أو المصروف.
- سعر الصرف يوحّد التقارير فقط؛ الحركة الأصلية تبقى بعملتها.

## الخصوصية والحدود

لا توجد مزامنة سحابية أو حساب مستخدم. حذف بيانات Safari أو إزالة بيانات الموقع قد يحذف السجلات المحلية، لذلك صدّر نسخة احتياطية دورياً إلى Files أو iCloud Drive.
